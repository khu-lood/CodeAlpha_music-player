# 🎵 JavaScript Music Player

A fully functional and interactive Music Player built using pure HTML, CSS, and JavaScript.

This project demonstrates DOM manipulation, event handling, audio control, and UI state management.

---

## 🚀 Features

- ▶ Play / Pause functionality
- ⏭ Next & Previous controls
- 🔀 Shuffle mode
- 🔁 Repeat mode
- ❤️ Like button (per-song memory)
- 🎶 Dynamic playlist
- 🌙 Dark mode support
- 🎯 Active song highlighting
-    Autoplay
---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Audio API
